# Changelog

## [0.14.2] - 2026-10-12
- 修正: Load のボタンの Disable Without Save（0.14.1）が、グラフの欄が空だと効かなかった（ボタンが有効になる時点では Graph Runner がまだ始まっていない）。Runner が始まったときにも確かめる
- 修正: Load のボタンが出ている間にセーブ・削除しても、押せる・押せないが変わらなかった（ポーズメニューなど）。`GraphSaveSlots.SlotChanged` で知らせ、確かめ直す
- 修正: セーブがあると、作者やほかのスクリプトが押せないようにしたボタンまで押せるようにしていた。押せないようにするだけにし、戻すのは自分が押せないようにしたときだけにする
- 修正: 同じ GameObject のボタンより前に CanvasGroup があると、そちらを変えていた。クリックを繋いだコンポーネントを変える
- 修正: 保存したノードがグラフから消えたセーブでも、Load のボタンを押せた。再開できるとき（`GraphSaveSlots.CanLoad`）だけ押せるようにする
- 修正: ADV Starter がシーンを作れずに戻したとき、グラフの Scene ノードが消したシーンを指したまま残ることがあった
- 修正: ADV Starter が Yarn プロジェクトのノードを読めなかったとき、何も言わなかった。警告を出す

## [0.14.1] - 2026-10-12
- 修正: 「続きから」（Graph Event Button の Load）が、セーブが無いうちも押せて、押しても何も起きなかった。スロットにセーブがあるときだけ押せるようにする（`Disable Without Save`、既定 on。同じ GameObject のボタンの `interactable` を変える）
- 修正: ADV Starter が、入れ子の Yarn プロジェクトがあると、ひな形のスクリプトを含まないプロジェクトを Story の Dialogue Runner に入れることがあった。一番近く、ひな形のノードを含むプロジェクトを入れる
- 修正: ADV Starter のシーンを作れなかったとき、片方のシーンが残り、グラフも開かなかった。作ったシーンを消してエラーを出し、グラフは開く
- 修正: Yarn Graph Bridge で置き換えた Yarn の In Memory Variable Storage が、使われないまま GameObject に残っていた。外す
- 修正: ADV Starter を使った直後の Undo に、閉じたシーンの物を指す手順が残っていた

## [0.14.0] - 2026-10-12
- 追加: ADV Starter が Title と Story のシーンも作り、グラフの Scene ノードに入れる。ツールバーの Play だけで最初から最後まで遊べる
  - `ADV Title`: 「New Game」（Raise `NewGame`）と「Continue」（スロット `auto` から Load）のボタン、EventSystem、このグラフの Graph Runner
  - `ADV Story`: Yarn Spinner の Dialogue System（Yarn プロジェクト・Yarn Graph Bridge（オートセーブ `auto`）・Graph Variable Storage 入り）
  - 今開いているシーンは切り替えない。未保存の無題のシーンが開いている・Play 中は、シーン無しで作るか尋ねる
- 修正: Yarn Spinner の Dialogue System のプレハブ（`GameObject > Yarn Spinner > Dialogue System`）に Yarn Graph Bridge を足しても、プレハブに最初から入っている In Memory Variable Storage が残り、Yarn の変数（`$Affection` など）がグラフのパラメータに届かなかった。Yarn の既定の In Memory Variable Storage は Graph Variable Storage に置き換える（ユーザーが選んだものは残す）
