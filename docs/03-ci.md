# 03 - CI

GitHub Actions でパッケージのコンパイルチェックだけを行う（テストの実行・リリースはしない）。
Unity 本体は起動しないため、Unity ライセンスや Secrets は不要。

## 仕組み（`.github/workflows/ci.yml`）

`main` への push / PR / 手動実行で走る。

1. Unity バージョンごとに並列で実行する（matrix）。対象は `ProjectSettings/ProjectVersion.txt` のバージョン（最小サポート）と、
   それ以降の各マイナーの最新パッチ（現在 `6000.3.25f1` / `6000.4.12f1` / `6000.5.2f1`）。
   マイナーごとに API が変わる（例: 6000.3 で `EntityId` が入り、6000.5 で `OnOpenAsset` が `EntityId` 版になり int 版の API がコンパイルエラーになった）ため
2. GameCI の Docker イメージ `unityci/editor:ubuntu-<version>-base-3` から
   `Editor/Data/Managed/UnityEngine/*.dll` を取り出す（`actions/cache` でバージョンごとにキャッシュ）
3. `.github/compile-check/` の csproj を `dotnet build` する。`-p:UnityVersion` からマイナー番号を取り出し、
   Unity 本体と同じ `UNITY_6000_N_OR_NEWER` シンボルを定義するので、`#if` によるバージョン分岐もそのバージョンの側がチェックされる

csproj は asmdef の境界を再現している。

| csproj | 対応 asmdef | 参照 |
|---|---|---|
| `Runtime.csproj` | `Reiga.VisualNodeEditor` | `UnityEngine*.dll` のみ（UnityEditor を使うとコンパイルエラーになる） |
| `Editor.csproj` | `Reiga.VisualNodeEditor.Editor` | Unity の全 DLL + Runtime |
| `Tests.Editor.csproj` | `Reiga.VisualNodeEditor.Tests.Editor` | 上記 + NUnit 3.5（Unity 同梱版と同じ API レベル） |

C# 9 / .NET Standard 2.1 でビルドするため、C# 10+ の構文もエラーになる。

asmdef を追加・変更したら csproj も合わせて更新すること。

## ローカルで実行する

インストール済み Unity の DLL と、そのバージョンを指定する（両方そろっていないとエラーになる）。

```sh
dotnet build .github/compile-check/Tests.Editor.csproj \
  -p:UnityManagedDir="C:/Program Files/Unity/Hub/Editor/6000.5.2f1/Editor/Data/Managed/UnityEngine" \
  -p:UnityVersion=6000.5.2f1
```

ビルド出力は `.github/compile-check/.build/`（git 管理外）に出る。

## 配布（Git ブランチから取り込む）

利用側の `Packages/manifest.json` で、`path` クエリと `#<ブランチ名>` を付けた Git URL を指定する。

```json
"net.reiga7953.visual-node-editor": "https://github.com/Ign1s-Reiga/UnityVisualNodeEditor.git?path=Packages/net.reiga7953.visual-node-editor#main"
```

- `#main` を別ブランチ名（例: `#feat/m1-minimal-editing`）やコミットハッシュに変えれば、その版を取り込める
- Unity は解決したコミットを利用側の `packages-lock.json` に固定する。ブランチの最新を取り込み直すには、Package Manager の Update か、lock の該当エントリ削除で再解決させる
- CI が通ったコミットだけを `main` に入れることで、`#main` を「安定版」として扱う
